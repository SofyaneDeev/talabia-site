# talabia-site

Public website of Talabia, served at https://talabiaapp.ma (GitHub Pages, branch `main`, folder `/`).

- `/` home page · `/privacy.html` · `/delete-account.html` · `/reset.html`
- `/app/` web version of the app
- `/c/?s=<shop>` public product catalogue · `/o/?c=<code>` one-tap order confirmation

The app's code lives in the private TALABIA repo; these files are copied from its `docs/` folder at each release.
